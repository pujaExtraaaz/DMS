How to use this ZIP — DMS Tally Connector

Run this bridge on the Windows PC where Tally is installed. It pulls vouchers from DMS and posts them into local Tally.

What this ZIP contains

  • start.bat — double-click to start (Windows)
  • connector.mjs — the bridge program
  • config.example.json — copy/edit as config.json
  • install-windows-task.ps1 — optional auto-start at logon
  • README.txt — short text guide
  • SETUP-GUIDE.html — this page

1. Before you start

  1. Install Node.js 18+ LTS on the Tally PC.
  2. Open Tally and load your company.
  3. Enable Tally HTTP/XML server (usually port 9000).
  4. Get the connector token from your DMS admin.

2. Install & configure

  1. Unzip this folder to C:\DMS-Tally-Connector (any path is fine).
  2. Double-click start.bat.
  3. On first run it creates config.json and opens Notepad.
  4. Edit values like this:
{
  "dms_url": "https://dms.extraaaz.com",
  "connector_token": "PASTE_TOKEN_HERE",
  "tally_url": "http://127.0.0.1:9000",
  "poll_seconds": 15,
  "batch_size": 10,
  "company": "Your Exact Tally Company Name"
}
  1. Save Notepad, close it, then run start.bat again.
  2. Keep the black console window open while you work.
Healthy start message looks like: Health OK — pending on server: N

3. Day-to-day use

  1. User posts invoice / payment / credit note in DMS.
  2. Item appears in DMS → Tally Queue as Pending.
  3. Within ~15 seconds the connector shows ... SENT.
  4. Queue status becomes Sent — check voucher in Tally.

4. Optional: start automatically at Windows logon

  1. Open PowerShell as Administrator.
  2. Run:
cd C:\DMS-Tally-Connector
Set-ExecutionPolicy Bypass -Scope Process -Force
.\install-windows-task.ps1

5. Troubleshooting

  • Unauthorized — token wrong; ask admin for TALLY_CONNECTOR_TOKEN.
  • Cannot reach DMS — PC needs internet; confirm dms_url.
  • Tally FAILED — Tally closed, wrong port, or master names mismatch.
  • Node not found — install Node.js, reopen command window.
  • Queue stays Skipped — admin must set TALLY_USE_CONNECTOR=true, then Retry.
Do not run this ZIP on the cloud/web server. It must run on the office PC next to Tally.
