2. Daily operating flow

Setup masters→ Purchase / Inward→ Landed cost→ Sales order→ Reserve / Deliver→ Invoice→ Collect payment

Hybrid sales: Warehouse mode = Order → Approve → Reserve → Deliver → Invoice. Van mode = Order/Invoice → Load sheet → Delivery → Settlement.

Organization setup

Menu → Organization Client Admin Company / Branch / Warehouse / FY / Sister Concerns

Why

Separate legal companies, godowns, and financial years without mixing ledgers.

How to use

  1. Create Business Group (Sister Concerns) if needed.
  2. Create Company → set GST/bank and Due Date Basis (Invoice or Inward date).
  3. Add Branches and Warehouses.
  4. Open Financial Years and mark current year.

Catalog & products

Menu → Masters Brand → Category → Sub Category → Products

Why

Item master with MRP, warranty, image, catalog link, and serial/batch tracking.

How to use

  1. Create Brand → Category → Sub Category.
  2. Create Product: SKU, prices, tax, specification, warranty, image.
  3. Set Tracking Type: None / Serial / Batch.
  4. Optional: Price Master for party-type pricing.

Upload product image on the product form (JPG/PNG). Image appears on product master / quotations.

Parties (customers / suppliers)

Menu → Masters → Parties Credit limit · Credit days · Party type

Why

Credit control starts here: limit, days, interest rate, dealer type, supplier/customer.

How to use

  1. Create Party with type Dealer / Customer / Supplier / Both.
  2. Enter credit limit, credit days, interest rate.
  3. Add addresses/contacts for billing, site, transit.
  4. Use this party on PO (supplier) or Sales Order (customer).

Purchase cycle (PO → GRN → Invoice → Landed cost)

Menu → Purchasing PO · Inward/GRN · Purchase Invoice · Freight · Landed Cost

Why

Stock comes in with serial/batch, vendor price check, and freight allocated into landed cost.

How to use

  1. Purchase Orders → Create → Approve.
  2. Inward / GRN → Receive against PO → assign serials/batches.
  3. Purchase Invoices → Book supplier bill (vendor price comparison shown).
  4. Freight Bills → Enter freight bill no. & amount.
  5. Landed Cost → Allocate freight/charges to items.

Duplicate serials are blocked with existing location/status. Resolve before posting.

Stock, transfers, serial lifecycle, FIFO/LIFO

Menu → Inventory Stock · Transfers · Adjustments · Serial Lifecycle · FIFO/LIFO

Why

Immutable stock ledger, warehouse moves, serial reserve→deliver→return, FIFO/LIFO costing.

How to use

  1. Stock — view on-hand by product/warehouse.
  2. Transfers — create → dispatch → receive.
  3. Adjustments — increase/decrease with reason.
  4. Serial Lifecycle — lookup → Reserve → Deliver → Return.
  5. FIFO / LIFO — set company method; value updates from cost layers.

Quotations, orders, invoices

Menu → Sales / Orders Quotation · Sales Order · Invoice · Region Policies

Why

Credit check before approval, region-brand rules, back-order for short stock, due-date based reservation.

How to use

  1. Optional: create Quotation (admin can see estimated profit).
  2. Create Order — choose party, items, warehouse or van mode.
  3. System checks credit limit / frozen party.
  4. Approve → stock reserved (warehouse) or proceed to van billing.
  5. Convert / create Invoice; due date follows company basis + party credit days.

Region Policies: restrict brands by region; overrides need reason + audit.

Van path: load sheet → delivery → settlement

Logistics · Delivery · Settlement

Why

Field sales / van fulfilment with dispatch and cash settlement.

How to use

  1. Dispatch (Load Sheets) — load invoices/stock on van.
  2. Deliveries — mark delivered / short / return.
  3. Cash Settlement — settle collections vs load.

Deals & multi-layer expenses

Menu → Deals & Margin

Why

Net margin after architect fee, site commission, installation, outward freight.

How to use

  1. Create Expense Types first.
  2. Open Deal → attach to invoice/project.
  3. Add expenses → approve → review in Margin Register.

Collections, cheques, credit notes

Menu → Payments Collections · Cheques/PDC · Credit Notes · Outstanding

Why

Allocate receipts, track PDC/security cheques, auto-freeze after bounce threshold (>3).

How to use

  1. Collections — record cash/UPI/bank/cheque against invoice(s).
  2. Cheques / PDC — register security or PDC (vendor or client).
  3. Mark bounce → bounce count increases; after threshold party freezes.
  4. Credit Notes — return / rate / scheme adjustment.
  5. Check Outstanding and Party Statement.

On invoice screen, send WhatsApp / Email / Notification — status is logged separately from accounting status.

Targets, schemes, interest

Menu → Performance

Why

Salesman targets, brand schemes/slabs, overdue interest on outstanding balance.

How to use

  1. Targets — set period + salesman/party/brand target; achievement from posted sales.
  2. Schemes — define brand/slabs/benefit; close period for settlement.
  3. Interest — preview overdue interest → post ledger/debit note.

HRMS

Menu → HRMS

Why

Employees linked to sales users for attendance, leave, claims, incentives.

How to use

  1. Create Employee → map branch/department/user.
  2. Mark Attendance; apply/approve Leave.
  3. Submit Expense Claims for approval/settlement.

CRM / Meta leads

Menu → CRM → Leads

Why

Capture Meta/Facebook/Instagram leads, assign, follow up, convert to party.

How to use

  1. Open Leads → create manually or receive via Meta webhook.
  2. Assign salesperson → log follow-ups.
  3. Qualify → convert to Party → create Quotation/Order.

Live Meta Graph fetch needs META_ACCESS_TOKEN in server env.

Dashboard, MIS reports, Tally

Dashboard · Reports · Integrations → Tally Queue

Key reports

  • Sales, Stock, Payments, Outstanding
  • Pending Orders (ordered/reserved/delivered/pending)
  • Salesman Outstanding, Aging, Margin
  • Purchase Register, Stock Ledger, Party Statement

How to use

  1. Dashboard → pick date range (Today / Week / Month / Custom).
  2. Open any report → filter by date, branch, party, brand, category, item, salesperson.
  3. Tally Queue → view posted XML sync; retry failed items.

For live sync from hosted DMS → office Tally, use the Tally Connector ZIP (recommended). Direct TALLY_ENDPOINT only works if Tally is reachable from the cloud server.

11. How to use the Tally Connector ZIP

DMS runs on the internet. Tally runs on your office PC. The connector is a small bridge you download and run on the Tally PC so vouchers sync automatically.

Download ZIPtally-connector.zip Open QueueSee Pending / Sent status Node.js 18+Required on the Tally PC

Step-by-step (Windows office PC)

A. Prepare Tally

  1. Open TallyPrime / Tally ERP 9.
  2. Load the company you sync with DMS.
  3. Enable Tally as HTTP/XML server (port usually 9000).
  4. Leave Tally open while the connector runs.

B. Install the connector

  1. Download tally-connector.zip from DMS → Tally Queue → Download Connector.
  2. Unzip to a folder, e.g. C:\DMS-Tally-Connector.
  3. Install Node.js 18+ LTS if not already installed.
  4. Double-click start.bat.

C. Fill config.json (first run opens Notepad)

  1. dms_url → https://dms.extraaaz.com
  2. connector_token → token from your DMS admin (TALLY_CONNECTOR_TOKEN in server .env)
  3. tally_url → http://127.0.0.1:9000 (change port if your Tally uses another)
  4. company → exact company name as shown in Tally (optional but recommended)
  5. poll_seconds → how often to check DMS (default 15)

Save the file, then run start.bat again. Keep the black window open.

D. Verify it works

  1. In DMS, post/issue an invoice (or payment).
  2. Open Tally Queue — item should be Pending.
  3. Connector log should show: #12 invoice ... SENT
  4. Queue status becomes Sent.
  5. Check the voucher inside Tally.

E. Auto-start at Windows logon (optional)

  1. Right-click PowerShell → Run as Administrator.
  2. cd C:\DMS-Tally-Connector
  3. Set-ExecutionPolicy Bypass -Scope Process -Force
  4. .\install-windows-task.ps1

Creates scheduled task DMS-Tally-Connector.

Troubleshooting

  • Unauthorized — wrong connector_token.
  • Cannot reach DMS — check internet / dms_url.
  • Tally FAILED — Tally not open, wrong port, or ledger/stock names don’t match Tally masters.
  • Items stay Skipped — ask admin to set TALLY_USE_CONNECTOR=true, then Retry on the queue row.
  • Node not found — install Node.js LTS and reopen start.bat.

12. Acceptance checklist (what client asked for)

  1. Due date from Invoice or Inward date (company setting)
  2. Product: spec, MRP, discount, warranty, price, image, catalog
  3. Vendor price comparison on purchase invoice
  4. Sister concerns without merged ledgers
  5. Pending order ordered/reserved/delivered/pending
  6. Freight bill → item landed cost
  7. Security cheques for vendors & clients
  8. Invoice WhatsApp / Email / Notification tracking
  9. Dashboard date filter
  10. FIFO & LIFO valuation
  11. Salesman targets + salesman outstanding
  12. Region-wise brand restriction + override
  13. Authorized back-order for unavailable stock
  14. Stock movement linked to source document
  15. Invoice traceable to party/item/price/expenses
  16. Credit limit block before credit-sale approval
  17. Serial/batch unique through lifecycle
  18. Outstanding = invoices − payments − credit notes
  19. Bounce threshold freezes party
  20. Interest from stored days/rate/overdue balance
  21. Targets & schemes from posted sales
  22. Critical actions auditable
  23. Reports filter date/branch/party/supplier/brand/category/item/salesperson
