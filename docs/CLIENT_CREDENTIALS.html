Install on phone (PWA)

  • Android Chrome: menu → Install app / Add to Home screen
  • iPhone Safari: Share → Add to Home Screen

After install, DMS opens like a mobile app with bottom navigation (Home, Orders, Stock, Collect, Menu).

What you can do with this account

  • Set up company, branches, warehouses, products and parties
  • Run purchase → inward → landed cost → stock
  • Create sales orders, invoices, deliveries and settlements
  • Collect payments, manage cheques, credit notes and outstanding
  • Use targets, schemes, interest, HRMS, CRM and MIS reports
